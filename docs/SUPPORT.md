# Suporte — política operacional inicial

Defina antes do go-live os canais oficiais, horários, idiomas e responsáveis por triagem. Incidentes críticos de segurança ou indisponibilidade devem ter rota de escalonamento separada do suporte comum.

## Severidade sugerida
- **P0** — indisponibilidade ampla, perda/corrupção de dados ou incidente crítico de segurança.
- **P1** — degradação importante sem workaround aceitável.
- **P2** — falha funcional com workaround.
- **P3** — dúvida, melhoria ou problema cosmético.

SLAs de resposta/resolução só devem ser publicados quando houver capacidade operacional para cumpri-los e devem variar conforme o plano/contrato.
